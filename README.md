# Mediarchive

애니메이션 학생들과 함께하는 세로 화면 학습 스케줄러.

[Mediarchive 실행](https://9jaywalking.github.io/mediarchive/)

## 기능

- 53개 순환기계 강의와 12명 학생, 하루·나기·시오리·레이의 캐릭터 움직임과 표정
- Wiki·J·JBL 이벤트, 실제 학습 타이머, 예습 보상, 레벨·성급·인연 성장
- 강의 시작 조언과 종료 질문, DM 복습 제안
- 학생·강의·자료를 연결하는 일정, 식사·휴식, 일일·주간 퀘스트
- 시간대별 배경과 대사, 시험 D-day, 학생별 통계
- 교복·사복·잠옷과 헤어 변화, 식사·시간에 맞춘 자동 전환
- 브라우저 저장과 JSON 백업·복원

## 복장

하루·나기·시오리·레이는 교복·사복·잠옷을 지원합니다. 기본은 07:00 교복, 저녁 식사 종료 후 사복, 23:00 잠옷입니다. 저녁 식사가 설정되지 않은 날은 19:00에 사복으로 바뀝니다.

설정 → 복장에서 시간을 바꾸고, 학생 → 프로필 → 감상에서 복장을 미리 볼 수 있습니다. 감상에서 직접 고른 복장은 해당 화면에만 적용합니다. 백업 v11에 복장 시간을 포함하며 이전 백업도 가져올 수 있습니다.

## 실행

정적 HTML/CSS/JavaScript 앱입니다. 빌드나 별도 서버 애플리케이션은 필요하지 않습니다.

```sh
python -m http.server 8765
```

브라우저에서 `http://localhost:8765/`를 엽니다. `file://`로 직접 열면 모듈과 모델을 불러올 수 없습니다.

GitHub Pages는 `main` 브랜치의 `/(root)`를 사용합니다. 모든 앱 리소스는 상대 경로를 사용합니다.

## 모바일

iPhone Safari에서 사이트를 연 뒤 공유 → 홈 화면에 추가합니다. Mediarchive 이름과 하루 아이콘을 사용합니다.

학습 상태는 사용 중인 브라우저에 저장됩니다. 기기 간 자동 동기화는 없으며, 설정의 내보내기·가져오기로 기록을 옮길 수 있습니다. 다른 주소에서 사용하던 기록도 백업 파일로 옮겨야 합니다. 백업은 개인적으로 보관합니다.

## 캐릭터와 글꼴

캐릭터는 한 장의 원화를 변형하는 Cubism 메시와 얼굴 표정 아틀라스로 표현합니다. Cubism Core는 Live2D 공식 CDN에서 불러오므로 인터넷 연결이 필요합니다. 전체 오프라인 실행은 지원하지 않습니다.

- UI: Wanted Sans
- 제목·학생 이름: LINE Seed Sans KR
- 대사: 고운돋움
- 숫자·영문 로고: Outfit

각 글꼴의 출처와 라이선스는 `assets/fonts/`에, 모델 생성 코드의 라이선스는 `scripts/LICENSE-stretchystudio.txt`에 포함되어 있습니다.
