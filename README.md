## Mediarchive 이름과 아이콘 — 2026-11-09

앱 제목, 홈 화면 이름, 설정 화면을 Mediarchive로 통일했습니다. 승인된 하루 원화의 웃는 얼굴을 편집해 앱 아이콘을 제작했습니다. `assets/icons/`에 브라우저용 16·32px, iPhone용 180px, 웹 앱용 192·512px를 포함합니다. 원본과 최종 프롬프트는 [ICON-PROMPT.txt](ICON-PROMPT.txt)에 기록했습니다.

`manifest.webmanifest`는 세로 화면과 단독 실행을 지정하며, 모든 경로는 GitHub Pages 하위 경로에서도 동작하는 상대 경로입니다. Safari에서 공유 → 홈 화면에 추가하면 Mediarchive 이름과 하루 아이콘을 사용합니다. 서비스 워커와 오프라인 캐시는 추가하지 않았습니다. iOS 실기기의 설치·표시는 별도 확인이 필요합니다.

기존 저장소 키와 백업 스키마는 유지합니다. 새 내보내기 파일명은 `mediarchive-backup.json`이며 이전 파일도 그대로 가져올 수 있습니다.

글꼴 출처·라이선스는 `assets/fonts/SOURCES.txt`와 각 `LICENSE-*.txt`에 포함합니다. 고운돋움과 Outfit은 원본 TTF를 글리프 변경 없이 WOFF2로 압축했습니다.

검증: 390×844 로비·학생 목록, 320×640 일정·입력 폼·DM 목록/대화·퀘스트·기록·종료 질문을 확인했습니다. 작은 화면의 가로 넘침, 선택지 줄바꿈과 글꼴 적용을 점검했으며 질문 테스트는 별도 로컬 주소에서 진행했습니다. 원래 앱의 07:40 일시정지 세션은 유지했습니다.

## 종료 질문과 표정 — 2026-11-09

`review-data.js`는 53강 110문항의 원리·연결 관계 복습 질문입니다. 1분 이상의 강의 연결 세션 저장 후 2문항을 표시하며, 세 번째 문항이 있는 1·2·6·16강은 JBL 또는 45분 이상 세션에서 3문항을 표시합니다. 선택지는 세션별로 섞어 저장합니다. 질문을 열 때 다른 진행 중 타이머도 일시정지하며, 문항 응답은 공부시간·XP·성급 완료를 추가하지 않습니다.

`review-engine.js`는 답변, 미응답, 중복 제출, 일일 한도와 회복을 관리합니다. 정답 +1·오답/모르겠어 −2, 학생별 하루 기본 보상 +6·감점 −6 한도이며 같은 문제는 같은 날 중복 보상/감점하지 않습니다. 재도전 정답은 이전에 실제로 차감된 점수를 최대 2점씩 반환하며 별도 기본 보상은 없습니다. 닫기·무응답에는 감점하지 않습니다. 첫 답변과 재도전은 분리해 보관합니다. 학생 통계에 귀속하며 기록 → 마지막 질문에서 다시 엽니다.

`review-ui.js`와 `review-dialogue.js`는 12명의 말투와 질문 화면을 관리합니다. 긴 해설은 순서대로 넘기며, 중도 종료·새로고침 후 남은 질문을 이어 봅니다. 백업 v10은 종료 질문을 포함하고 v1–9도 계속 가져옵니다. 저장 실패 시 답변 화면을 넘기지 않습니다. 같은 세션 ID의 질문·보상은 중복 생성하지 않습니다.

`expressions.js`와 `assets/expressions/`의 아틀라스 4장은 기존 원화의 눈·입 좌표에 정합합니다. WebGL에서 얼굴 영역만 합성하므로 머리·옷·배경은 교체하지 않습니다. 표정 전환은 260ms, 움직임 줄이기 설정에서는 즉시 전환하며 몸짓을 억제합니다. 이는 독립 눈·입 파츠가 있는 Cubism 리깅이나 립싱크는 아닙니다. 모델이 있는 4명은 표정과 움직임, 나머지 8명은 질문·성격별 대사·인연 기록을 지원합니다. 감상 → 표정에서 수동 확인할 수 있습니다.

검증: 질문 범위·중복·일일 한도·회복·병합·얼굴 좌표 검사, 기존 성장·일정·통계 검사, 브라우저에서 저장 후 자동 질문·정오답 표정·새로고침 복구·재도전 회복. iOS Safari 실기기 검증은 별도입니다.

## 하루 원화와 움직임

최신 `assets/haru-fresh-airy.png`를 실제 `haru.moc3`와 `haru.model3.json`에 연결했습니다. 원화 제작 기록은 `HARU-FRESH.txt`, `HARU-AIRY.txt`.
